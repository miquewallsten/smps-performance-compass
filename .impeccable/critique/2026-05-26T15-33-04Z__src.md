## Remaining Priority Issues

### 🟠 P1: Evaluation form still long on desktop — accordion helps mobile, but desktop shows one section at a time with no way to see overall progress at a glance
The accordion improves mobile experience significantly, but on desktop the user still can't see how many questions remain across all sections without opening each one. Consider a sticky sidebar or mini-map showing section completion status while scrolling through all questions.

### 🟡 P2: No draft autosave — leaving the self-evaluation page loses all progress
If a user accidentally navigates away or the browser crashes, all responses are lost. No localStorage persistence or draft recovery mechanism exists.

### 🟡 P2: Inconsistent surface treatment across pages not yet updated
Reports.tsx and Evaluations.tsx received `smps-section-title` and `smps-surface-card` via bulk sed, but some pages (UserManagement, Vacations, Communications, CopilotChat, PersonalObjectives) still use the old `bg-card rounded-xl border p-6` pattern. The visual rhythm improvement is partial.

### 🔵 P3: Login page could benefit from a subtle entrance animation on the card
The `smps-fade-up` class is applied but the gradient overlay competes with the card. Consider a lighter overlay or a more focused card entrance.
